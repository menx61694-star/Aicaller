# Aicaller

AI-powered incoming-call screening and human takeover agent.

## Development rule

This project follows the Aicaller exhaustive roadmap. No phase, step, or sub-step is considered complete until it is implemented (where applicable), tested, and verified.

## Current phase

**Phase 0 — Architecture Freeze**

The repository is currently being established from an empty baseline. No existing application source code has been modified or removed.

## Core goals

- Real-time incoming-call handling
- AI call screening
- Low-latency streaming voice pipeline
- VAD and barge-in
- Human takeover / call bridge
- Whisper and coach modes
- Caller identification and short-term context
- Intent, spam, IVR and voicemail detection
- Recording and live transcription
- Post-call summaries and actions
- Notifications and optional calendar/CRM actions
- Security, privacy, failure recovery, observability and cost controls

See `docs/PROJECT_CHECKLIST.md` and `docs/ARCHITECTURE.md` for the controlled implementation plan.
