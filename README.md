# Aicaller

AI-powered incoming-call screening and human takeover agent.

## Current phase

**Phase 1 — Telephony Foundation**

Phase 0 architecture is frozen. Phase 1 builds the production-shaped backend foundation without hard-coding provider behavior into the domain layer.

## Stack

- Python 3.11+
- FastAPI
- Provider adapter boundary
- PostgreSQL / Redis / object-storage interfaces reserved
- LiveKit Agents realtime framework target
- OpenAI Realtime initial AI adapter target
